# LED Pedestre

## Sobre o projeto

O LED Pedestre é um sistema de mapeamento urbano que tem como objetivo identificar os locais da cidade que possuem ou não iluminação LED nas faixas de travessia de pedestres.

## Objetivo

Facilitar a visualização da infraestrutura urbana e contribuir para a conscientização sobre segurança nas travessias de pedestres.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- Git e GitHub

## Funcionalidades

- Mapa interativo.
- Identificação de pontos com LED.
- Identificação de pontos sem LED.
- Cadastro de usuários.
- Login.
- Registro de novas travessias.
- Filtro por situação.

## Como executar

Abra o projeto utilizando o Visual Studio Code e execute com a extensão Live Server.

## Observação

Os pontos iniciais são fictícios e servem apenas para demonstração. Os registros locais ficam armazenados no navegador e não são compartilhados entre usuários.
